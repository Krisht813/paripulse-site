Common questions

How do demo deposits work?

Open Deposits, choose an amount and asset, then submit a demo receipt. A demo admin approves it from the review queue and the balance updates.

Is any real money involved?

No. Every address, balance, and transaction in this dashboard is simulated in your browser. Never send real funds to a demo address.

Why is my balance stored locally?

This build uses browser storage until the Firebase backend is connected. Clearing site data or resetting demo data restores the starting values.

How do I change my password?

Use Settings → Security to open the password reset flow. Reset emails are sent by Firebase Authentication.
